# План переноса скриптов бэктеста

> Исполнение в текущем проекте. Требования: запрос пользователя и постоянные правила AGENTS.md из беседы.

**Цель:** переместить четыре скрипта `backtest*.py` в `backtest/`, сохранив расчёты, параметры, запускатели и создание отчётов.

**Подход:** оформить `backtest` как пакет Python; при запуске файла добавить корень проекта в путь импорта. Пути к исходникам для SHA256 определять от корня проекта. Кэш длительности оставить в корневой `.duration_cache`; относительные пользовательские пути по-прежнему считать от рабочей папки.

**Технологии:** Python, unittest, SQLite, существующие numpy/pandas/plotly; CMD и PowerShell.

## Ограничения

- Пояснения, комментарии и документация — на русском языке.
- В начале изменённых скриптов должны быть актуальные описания и примеры запуска.
- В каждой папке изменённых скриптов должен быть актуальный README.md.
- Торговые алгоритмы и пользовательские данные не изменяются.

## Риски для проверки

- Импорты `source` при прямом запуске файла из подпапки.
- Импорт соседнего бэктеста при запуске через `python -m`.
- Создание отчётов из посторонней рабочей папки, включая SHA256 исходников.
- Сохранение прежнего стандартного пути кэша длительности.
- Актуальность CMD-запускателей, тестовых импортов и инструкций.
