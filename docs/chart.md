# График дельта-баров RTS/MIX

## Запуск

Откройте `start_chart.cmd` двойным щелчком. Или из папки проекта:

```powershell
.\.venv\Scripts\python.exe chart_delta_bars.py
```

Примеры:

```powershell
.\.venv\Scripts\python.exe chart_delta_bars.py --symbol MIX
.\.venv\Scripts\python.exe chart_delta_bars.py --symbol RTS --start 2026-09-15 --end 2026-09-18
.\.venv\Scripts\python.exe chart_delta_bars.py --symbol MIX --db C:\data_quote\MIX_delta_bars.sqlite3
```

По умолчанию RTS читает `C:\data_quote\RTS_delta_bars.sqlite3`, MIX — `C:\data_quote\MIX_delta_bars.sqlite3`. Переключение инструмента доступно в окне. `--data-dir` задаёт другую папку этих двух файлов. Явно указанный `--db` или кнопка **База…** закрепляют один выбранный файл для обоих положений переключателя; это удобно для общей базы с двумя инструментами. Чтобы вернуться к двум стандартным файлам, перезапустите без `--db`.

При нескольких наборах параметров в базе появляется список наборов. Их бары не смешиваются.

## Управление

- Начальный диапазон — последние 30 календарных дней доступной истории; в кадре примерно последние 200 баров.
- **С / По → Показать** — загрузить указанный диапазон включительно.
- **Весь диапазон** — показать все уже загруженные бары на одном экране.
- **Обновить / Ctrl+R** — перечитать базу после дозаписи. Если конечная дата совпадала с последним днём базы, она продлевается до нового последнего дня.
- Колесо мыши — масштабирование, перетаскивание — перемещение по истории. Перекрестие и нижняя карточка показывают параметры выбранного бара.
- Флажки включают ALF, Volume Stops, объём, границы дней, метки неполных баров и панель длительности.
- Изменение **α** пересчитывает фильтр после завершения редактирования поля. **Отступ** задаёт расстояние точек от low/high в пунктах цены; запоминается отдельно для тикеров в текущем сеансе.

## Индикаторы и время

График повторяет оформление [образца chart_finplot](https://github.com/Alkor135/chart_finplot/blob/main/img.png). Рекурсия ALF и условия объёмных сигналов взяты из [chart_from_cache_csv.py](https://github.com/Alkor135/chart_finplot/blob/main/chart_from_cache_csv.py).

**ALF** — фильтр Лагерра по close, начальная α=0.4. Коэффициент фиксирован до изменения пользователем. В отличие от нулевого начального состояния образца, четыре состояния фильтра инициализируются первой доступной ценой. Это исключает искусственный стартовый выброс. Фильтр рассчитывается по всей истории до конца выбранного диапазона, а затем выбирается видимый участок. Поэтому перенос начальной даты не меняет ALF на общих барах. Будущие бары не используются. Неполные дневные остатки входят в ALF. Через ночные ценовые разрывы, включая склейку, линия продолжается; автоматического определения конкретного контракта в этой базе нет.

**Volume Stops** — четыре условия исходного примера: две падающие свечи и затем растущая для Long, две растущие и затем падающая для Short; объёмы трёх свечей строго возрастают или строго убывают. Равенство open/close обрабатывается так же, как в образце: doji удовлетворяет обоим условиям направления. Синие точки обозначают возрастающий объём, зелёные — убывающий. Все три бара должны быть полными и принадлежать одному дню. Сигнал становится известен при закрытии третьего бара. Эти отметки не являются автоматически рассчитанными ценами входа или стоп-приказами.

**Неполный бар** отмечен янтарным треугольником. Отключение флажка скрывает только треугольники, сами бары остаются на графике. Пунктирные вертикали разделяют календарные московские даты.

На оси X каждый бар занимает одинаковое место независимо от длительности. Внутренний номер уникален, поэтому одинаковые временные метки не объединяют свечи. Подписи показывают московское время начала, в карточке — начало и конец с сохранением дробных секунд. Доли секунды источника искусственные; график не превращает их в биржевые временные метки.

Гистограмма показывает весь объём бара. Нижняя отключаемая панель показывает длительность в минутах; в карточке длительность указана в секундах.

## База и окружение

Просмотрщик использует SQLite `mode=ro` и `query_only`. Он не пересчитывает дельта-бары и не записывает индикаторы в базу. Соединение закрывается после загрузки; конвертер может затем дозаписывать новые дни. В режиме WAL SQLite может использовать служебные файлы `-shm` и `-wal` для согласованного чтения.

Зависимости закреплены в `requirements-chart.txt`; проверено на Python 3.13.13, finplot 1.9.7, PyQt6 6.9.1 / Qt 6.9.2, pandas 2.2.3 и NumPy 2.2.6. Отдельное `.venv` в этом проекте не меняет окружение загрузчика котировок.

Установка заново:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-chart.txt
.\.venv\Scripts\python.exe patch_finplot.py
.\.venv\Scripts\python.exe chart_delta_bars.py
```

### Локальное исправление finplot

В опубликованном finplot 1.9.7 присутствует блок, вызывающий `os._exit(1)` при русской/белорусской локали. На этой машине импорт завершал процесс до появления окна. `patch_finplot.py` удаляет только этот точно известный блок из установленной копии finplot 1.9.7. Остальной исходник и настройки Windows не меняются. Скрипт откажется править другую версию или неузнаваемый блок. Повторное применение безопасно; `start_chart.cmd` проверяет исправление перед запуском.

finplot распространяется по лицензии MIT. Оригинальная лицензия и сведения об авторе сохраняются в установленном пакете. После переустановки finplot примените исправление повторно.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest -v tests.test_chart_data tests.test_chart_gui
```

GUI-тесты создают собственное окно Qt в режиме offscreen и временные базы. Проверяются формулы, отсутствие будущих данных, одинаковые временные метки, независимость ALF от начала видимого диапазона, отсутствие записи, управляющие элементы и импорт при русской локали. Реальные примеры изображений: `chart_RTS_preview.png` и `chart_MIX_preview.png` в этой папке.
