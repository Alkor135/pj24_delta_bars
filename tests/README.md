# Проверки проекта

Все проверки запускаются из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m unittest -v tests.test_backtest_launch
.\.venv\Scripts\python.exe -m unittest -v tests.test_backtest_stochastic
.\.venv\Scripts\python.exe -m unittest -v tests.test_backtest_heikin_ashi
.\.venv\Scripts\python.exe -m unittest -v tests.test_chart_supertrend
.\.venv\Scripts\python.exe -m unittest -v tests.test_chart_semafor
.\.venv\Scripts\python.exe -m unittest -v tests.test_chart_semafor_simulate
```

`test_backtest_launch.py` проверяет расположение четырёх `backtest*.py` в пакете
`backtest`, прямой и модульный запуск справки из корня, запуск из папки `backtest`
и посторонней рабочей папки без `PYTHONPATH`. Полные запуски на временных SQLite/ZIP
проверяют создание отчётов, относительные пути результатов, SHA256 исходников и
сохранение стандартного кэша длительности в корневой `.duration_cache`.

`test_backtest_stochastic.py` проверяет формулу Stochastic, прогрев, исключение
неполных баров, причинность индикаторов, пересечения 20/80 с ALF и базу сравнения
без стохастика. Модель исполнения проверяется на тиках с разрывами цены,
касанием цели, короткой позицией, затратами за круг и внутритиковой просадкой.
Входы во время открытой позиции, на тике выхода и с непригодным стопом запрещены.
Дополнительно проверяются сверка внутрибара high/low с тиками, полное покрытие
исходных строк, число баров по журналу, сохранение дней прогрева и разделение
2026 года с последующей историей.

`test_backtest_heikin_ashi.py` проверяет рекурсивные формулы Heikin Ashi,
исключение неполных баров, причинность и серии одной/двух свечей. Проверяются
исполнение следующим реальным тиком, переворот с затратами на обе позиции,
запрет позднего входа, закрытие сессии и просадка по всем тикам внутри сделки.
Журнал для сверки должен включать и историю прогрева до выбранного начала;
границы статистики при этом остаются в запрошенном периоде.
Интеграционный пример с временной базой и ZIP проверяет, что повреждённый
экстремум до начала теста останавливает запуск до торговли.

`test_chart_supertrend.py` сверяет Supertrend с вручную рассчитанными значениями:
ATR Уайлдера с ценовыми разрывами, прогрев, подтягивание полос, развороты и
касание без переключения. Проверяет причинность, неправильные параметры/OHLC,
чтение SQLite без записи и одинаковые значения на пересекающихся диапазонах
дат. В режиме offscreen проверяет новое окно, изменение периода/множителя,
включение обеих цветных линий, короткую историю, ошибки и пустой диапазон.
Проверка геометрии линии требует видимый отрезок, даже если первое значение
Supertrend появилось только на последнем баре.
Длинная история и масштабирование проверяют, что прореживание не удаляет
короткую последнюю ветвь индикатора.

Остальные `test_*.py` проверяют конвертер, просмотрщик и ранее существовавшие
стратегии длительности. Подробные команды приведены в корневом README.md.

`test_chart_semafor.py` проверяет три независимых уровня ZigZag «Семафора»,
замену последней вершины, Depth/Deviation/Backstep, масштаб допуска шагом цены
и простые SMA цветных островов. Временная SQLite проверяет прогрев до начальной
даты, отсутствие будущих баров и вычислений ALF/StopVolume, точность времени,
выбор набора и сохранность базы. Проверка Qt offscreen охватывает свечи,
изменение глубины, переключатели, панель длительности, ошибку и пустой диапазон.
Отдельный ценовой гэп проверяет, что вертикальный автомасштаб при приближении
включает медленную SMA и метки СФ с большим декоративным отступом.

`test_chart_semafor_simulate.py` проверяет последовательное воспроизведение
реальных баров, отсутствие влияния будущих экстремумов, прогрев до начальной
даты, точность времени и чтение SQLite без записи. Проверки Qt offscreen
охватывают паузу, один шаг, изменение интервала на ходу, завершение и перезапуск,
появление и перенос меток СФ в пресетах NUF/FXi, неполные бары и границы дней. Обновление должно
сохранять холст, свечной объект, видимость индикаторов и выбранный масштаб.

## Проверки графиков QUIK

`test_chart_realtime.py` проверяет изменяемую свечу, новые бары, прогрев,
полночь МСК, освобождение worker, независимость двух Qt-окон, подхват ночного
обновления истории/порога и предупреждение о новом пороге после первой сделки.
Запуск из корня: `.\.venv\Scripts\python.exe -m unittest -v tests.test_chart_realtime`.

`test_realtime_feed.py` проверяет JSON по настоящим локальным TCP-сокетам,
выбор контракта, независимые HTTP-курсоры RTS/MIX и сохранение callback
при разрыве, таймауте снимка и смене даты. Запуск:
`.\.venv\Scripts\python.exe -m unittest -v tests.test_realtime_feed`.

`test_realtime_data.py` проверяет прошлое окно калибровки, кэш порогов,
ручной порог и исключение текущего дня. Запуск из корня:
`.\.venv\Scripts\python.exe -m unittest -v tests.test_realtime_data`.

`test_realtime_core.py` проверяет tick rule, неделимость сделки, совпадение
с пакетным построителем, поздние/повторные сделки, календарный сброс и журнал.
Запуск из корня: `.\.venv\Scripts\python.exe -m unittest -v tests.test_realtime_core`.
