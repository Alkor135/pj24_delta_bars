# Проверки проекта

Все проверки запускаются из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m unittest -v tests.test_backtest_stochastic
.\.venv\Scripts\python.exe -m unittest -v tests.test_backtest_heikin_ashi
```

`test_backtest_stochastic.py` проверяет формулу Stochastic, прогрев, исключение
неполных баров, причинность индикаторов, пересечения 20/80 с ALF и базу сравнения
без стохастика. Модель исполнения проверяется на тиках с разрывами цены,
касанием цели, короткой позицией, затратами за круг и внутритиковой просадкой.
Входы во время открытой позиции, на тике выхода и с непригодным стопом запрещены.
Дополнительно проверяются сверка внутрибара high/low с тиками, полное покрытие
исходных строк, число баров по журналу, сохранение дней прогрева и разделение
2026 года с последующей историей.

`test_backtest_heikin_ashi.py` проверяет рекурсивные формулы Heikin Ashi,
исключение неполных баров, причинность и серии одной/двух свечей. Проверяются
исполнение следующим реальным тиком, переворот с затратами на обе позиции,
запрет позднего входа, закрытие сессии и просадка по всем тикам внутри сделки.
Журнал для сверки должен включать и историю прогрева до выбранного начала;
границы статистики при этом остаются в запрошенном периоде.
Интеграционный пример с временной базой и ZIP проверяет, что повреждённый
экстремум до начала теста останавливает запуск до торговли.

Остальные `test_*.py` проверяют конвертер, просмотрщик и ранее существовавшие
стратегии длительности. Подробные команды приведены в корневом README.md.
